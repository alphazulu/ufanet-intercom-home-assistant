## HACS review fixes

### Non-blocking time-zone loading

Archive ranges and URLs, call-event calendars, motion timelines and MP4 export
previously constructed `zoneinfo.ZoneInfo` inside asynchronous Home Assistant
service handlers. Loading an uncached time-zone file can block the event loop.

The integration now resolves each provider time-zone name with
`await homeassistant.util.dt.async_get_time_zone(...)`. The resulting `tzinfo`
object is passed into synchronous formatting helpers, so those helpers perform
only in-memory date/time conversion. Invalid provider zones retain the existing
Home Assistant default-zone fallback.

### Administrator-only guest access

Guest invitation URLs and temporary web keys are access credentials. Every
service that reads or changes that access surface is now registered with Home
Assistant's admin-service wrapper:

- `get_guest_access`;
- `create_temporary_guest_link`;
- `revoke_temporary_guest_link`;
- `create_guest_invite`;
- `forget_guest_invite`;
- `revoke_shared_access`.

The backend check is authoritative and does not rely on frontend visibility.
Calls from a non-admin Home Assistant user fail before device resolution or any
Ufanet API request.

The candidate adds regression coverage for the asynchronous time-zone loader,
invalid-zone fallback and non-admin rejection of all six guest/shared-access

full-package coverage thresholds, standalone-module coverage floors, frontend
