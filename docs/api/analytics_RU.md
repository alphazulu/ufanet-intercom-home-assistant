# Аналитические события камер UCAMS

[English version](analytics.md)

Здесь зафиксированы read-only контракты аналитики камер, наблюдавшиеся в
официальном Android-клиенте. Они не включаются в runtime Home Assistant до
подтверждения реального запроса и ответа на тестовой учётной записи.

## Метаданные возможностей камеры

**Статус: Observed; сам endpoint метаданных камеры имеет статус Confirmed**

Существующий запрос `POST /api/v0/cameras/this/` может включать поле
`analytics`. Android-клиент обрабатывает его как список строковых типов
аналитики.

Исследовательский probe запрашивает только:

```json
{
  "fields": ["number", "analytics", "tariff", "timezone"],
  "numbers": ["<CAMERA_NUMBER>"]
}
```

Для capability discovery не запрашиваются live-, archive- или screenshot-токены.

## Архив событий с фильтром по типу

**Статус: Observed**

Android-клиент читает один тип аналитики запросом:

```http
POST https://cloud.ucams.ru/api/v0/analytics/<type>/report/
Authorization: Bearer <UCAMS_TOKEN>
Content-Type: application/json
```

Наблюдаемые поля запроса:

```json
{
  "camera_number": "<CAMERA_NUMBER>",
  "start": "<ISO-8601>",
  "end": "<ISO-8601>",
  "limit": 5,
  "order_by_date": "desc"
}
```

Первый этап probe намеренно ограничен типами `motion_alarm` и
`perimeter_security`. Распознавание лиц и автомобильных номеров, тепловые
данные, анализ толпы, каски, снимки, свободный текст и URL медиа не входят в
область интеграции.

В модели события наблюдаются имена полей `id`, `time`, `type`,
`camera_number`, `duration`, `full_screenshot_url`, `protocol`, `text` и
специфичное для движения `length`. Их наличие в live-ответе и точная оболочка
ответа пока не подтверждены.

## Граница приватности

Probe сообщает только HTTP-статусы, количества, наличие безопасных типов,
форму оболочки и имена известных полей. Номера камер, ID и timestamps событий,
текст, токены, URL медиа, изображения и результаты распознавания не печатаются.

Production-реализация должна хранить только приватный курсор от повторов и
грубые тип/время события, необходимые Home Assistant. Сырая история и
медиа/результаты распознавания не должны попадать в сущности или диагностику.
