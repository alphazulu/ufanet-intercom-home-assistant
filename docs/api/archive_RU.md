## Диапазоны доступной записи

**Статус: Confirmed**

Доступность архива запрашивается у медиасервера камеры с использованием `token_r`:

```text
https://<MEDIA_SERVER>/<CAMERA_NUMBER>/recording_status.json?from=0&request=ranges&token=<TOKEN_R>
```

Наблюдаемый элемент диапазона:

```json
{
  "from": 1700000000,
  "duration": 3600
}
```

- `from` — Unix timestamp в секундах;
- `duration` — длительность в секундах.

На тестируемой камере возвращалось несколько диапазонов. Нельзя предполагать непрерывную запись: перед запросом фрагмента лучше получить ranges и проверить покрытие нужного интервала.

## HLS архива

**Статус: Confirmed**

Проверенная форма playlist:

```text
https://<MEDIA_SERVER>/<CAMERA_NUMBER>/archive-<START_UNIX>-<DURATION>.m3u8?token=<TOKEN_R>
```

Проверенный запрос вернул HTTP 200.

- `<START_UNIX>` — начало фрагмента в Unix time;
- `<DURATION>` — длительность в секундах.

## Прямой arbitrary MP4

**Статус: Not supported в проверенной форме**

Был отдельно проверен URL:

```text
https://<MEDIA_SERVER>/<CAMERA_NUMBER>/archive-<START_UNIX>-<DURATION>.mp4?token=<TOKEN_R>
```

Тестируемый сервер вернул **HTTP 403**.

Не следует считать эту форму рабочим endpoint скачивания MP4, пока новые тесты не докажут обратное.

## Рабочий экспорт MP4

**Статус: Confirmed в рамках проекта**

Интеграция Home Assistant экспортирует MP4 следующим образом:

1. проверяет запрошенный интервал по диапазонам архива;
2. получает HLS playlist архива;
3. выполняет remux через ffmpeg с stream copy (`-c copy`);
4. сохраняет MP4 в Home Assistant Media.

Такой подход не требует перекодирования, если исходные кодеки совместимы с контейнером MP4.

## Глубина архива

Метаданные камеры могут содержать сведения тарифа и `dvr_hours`. У тестируемой камеры наблюдалось 120 часов архива (5 дней).

**Статус: Observed; глубина архива зависит от камеры/тарифа.**

## Работа со временем

На границах API следует использовать timezone-aware datetime. В Unix timestamp переводить только для запросов медиасервера, где это требуется явно. Нельзя менять timezone у уже распарсенного времени без реального преобразования момента времени.
