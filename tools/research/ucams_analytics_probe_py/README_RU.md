# Read-only probe аналитических событий UCAMS

Утилита проверяет доступность безопасных для автоматизаций событий камеры до
их включения в интеграцию Home Assistant.

Probe выполняет только чтение:

1. получает камеры, связанные с домофонами;
2. обменивает JWT Ufanet на временный bearer-токен UCAMS;
3. запрашивает только минимальные metadata `number`, `analytics`, `tariff` и
   `timezone`;
4. если камера объявляет поддержку, проверяет последние события типов
   `motion_alarm` и `perimeter_security`.

Операции настройки аналитики, камеры или тарифа не выполняются. Типы
`face_recognition`, `car_number`, `thermal_vision`, `crowd` и `helmet` не
запрашиваются.

## Установка и запуск

Из корня репозитория:

```cmd
cd tools\research\ucams_analytics_probe_py
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python probe.py
```

Логин можно передать через `--username` или переменную `UFANET_USERNAME`.
Пароль безопаснее вводить в скрытом приглашении. Для автоматического локального
запуска поддерживается переменная `UFANET_PASSWORD`, но её нельзя публиковать.

## Что можно прислать для анализа

Присылайте только строки `[OK]`, `[RESULT]`, `[INFO]` и `[ERROR]`.

Probe не печатает:

- договор и пароль;
- JWT Ufanet или UCAMS;
- номера камер и идентификаторы событий;
- точные timestamps;
- адреса, названия и свободный текст;
- URL снимков и сами изображения;
- распознанные лица или автомобильные номера;
- исходные JSON-ответы.

Вывод содержит только HTTP-статусы, количества, булевы capability-признаки,
фиксированные безопасные типы и названия известных полей схемы.

## Параметры

```cmd
.venv\Scripts\python probe.py --hours 24 --limit 5 --max-cameras 5
```

- `--hours` — окно от 1 до 168 часов;
- `--limit` — от 1 до 25 записей на камеру и тип;
- `--max-cameras` — не более 10 камер;
- `--ufanet-base-url` и `--ucams-base-url` предназначены только для
  изолированных тестов.
