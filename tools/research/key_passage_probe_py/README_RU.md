# Read-only probe физических ключей и журнала проходов

Утилита проверяет наблюдавшиеся в официальном Android-клиенте read-only API-контракты физических ключей до/вместе с их использованием в интеграции Home Assistant.

Probe выполняет только чтение:

1. получает список доступных функций аккаунта;
2. определяет домофоны с поддержкой записи ключей;
3. получает список физических ключей;
4. запрашивает до пяти последних проходов для каждого поддерживаемого домофона.

Probe **намеренно не выполняет** state-changing операции:

- `POST /api/v4/key/skud/<id>/auto_collect/enable/` (60-секундный enrollment);
- `POST /api/v4/key/edit/` (переименование);
- `POST /api/v4/key/skud/<id>/delete/key/` (удаление).

Эти контракты документируются отдельно в `docs/api/keys_RU.md`. Enrollment в
validation-ветке Home Assistant должен проверяться только явным нажатием
**«Добавить физический ключ»** с новым незарегистрированным ключом. Переименование и
особенно destructive delete требуют отдельного controlled live-теста и не входят в
этот read-only probe.

## Запуск в Windows

Переключитесь на ветку, указанную в сообщении разработчика, затем выполните:

```cmd
cd tools\research\key_passage_probe_py
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python probe.py
```

Логин/договор и пароль запрашиваются интерактивно. Пароль при вводе не
отображается. Вместо интерактивного ввода можно использовать локальные переменные
окружения `UFANET_USERNAME` и `UFANET_PASSWORD`.

## Конфиденциальность

Probe намеренно не печатает:

- договор, пароль или JWT;
- ID домофона и адрес;
- `external_id` физического ключа;
- ID и имя ключа;
- устройства, связанные с ключом;
- точное время прохода;
- исходные JSON-ответы.

Вывод содержит только HTTP-статусы, количества, булевы признаки поддержки и
названия подтверждённых полей схемы.

Для проверки достаточно прислать строки `[OK]`, `[RESULT]`, `[INFO]` и `[ERROR]`.
Не присылайте переменные окружения, дамп трафика или исходные ответы сервера.

## Параметры

```cmd
.venv\Scripts\python probe.py --page-size 5 --max-intercoms 10
```

- `--page-size` — от 1 до 25 записей для одного домофона;
- `--max-intercoms` — ограничение количества запросов истории;
- `--ufanet-base-url` — альтернативный сервер только для изолированных тестов.
